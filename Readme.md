# Currency Tracker

## What it does
Fetches live exchange rates from the ExchangeRate API and saves them to a JSON file.

## API used
`https://api.exchangerate-api.com/v4/latest/USD`

## How to run
1. Install requests: `pip install requests`
2. Run: `python tracker.py`

## Output
Prints live rates and saves them to `rates.json`
